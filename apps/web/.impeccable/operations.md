# Operations settings

Mode: Operate. Practice owners and admins review saved delivery and call work; server authorization remains authoritative. The frozen FW-37 contract defines the content and actions. This extends the existing Settings surface without changing the design system.

## Direction contract

THESIS: Make stalled work actionable through a specific reviewed decision, without presenting an empty queue as proof of service health.

OWN-WORLD: Preserve DentaBill’s pale working canvas, pine controls, Inter working typography, fine dividers, native selects and native modal review pattern. No new assets or tokens.

STORY: Read work counts, filter delivery or call work, inspect the exact current delivery snapshot, and approve only the action the server permits. Uncertain or accepted calls lead to existing claim/call pages.

FIRST VIEWPORT: Operations title and refresh action, compact label/count rows, delivery work heading and filter followed by a bounded table. Call follow-up sits next in the same reading order. Narrow layouts wrap controls and retain essential delivery identity, attempts and review action.

FORM: Pinned Settings extension; no concept seed or new identity selection. The review dialog protects the exact snapshot and requires a new approval after it changes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Verification preserves incumbent DESIGN.md and theme tokens. No shipping rasters are created; desktop/mobile screenshots are development-only evidence.
